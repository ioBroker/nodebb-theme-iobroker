ioBroker theme for NodeBB
====================

This theme is based on Harmony (the default theme for NodeBB 4.x) and modified for forum.iobroker.net

## Compatibility

- NodeBB ^4.0.0

## Installation

Install via npm:

```bash
npm install nodebb-theme-iobroker
```

## Features

- Quick reply functionality
- Hide subcategories option
- Hide last post on categories view option
- User-configurable theme settings
- Admin panel for theme configuration

## Development

```bash
# Install dependencies
npm install

# Lint code
npm run lint
```
